# Fractal Knot

## Overview

Add an iterated cable knot -- a base knot recursively wound
into a self-similar fractal knot.

An iterated knot reached by **cabling**: take a base knot, then replace it by a thinner strand that winds helically around it at a higher frequency and smaller radius. Repeat, and each pass adds a finer level of coiling, so the limit curve is self-similar at every scale.

This is the satellite-knot route to a fractal knot, distinct from the planar tile-substitution of the [substitution knot](substitution_knot.md) generator though it produces a similar coiled family. Its advantage is that it lives in genuine 3-space rather than in a diagram, which removes the hardest part of the problem — see below.

### Using it

1. **Add it** from *Add ▸ Mesh ▸ Math Art ▸ Knots & Curves ▸ Fractal Knot*.
2. **Pick the Base Knot** — the curve everything winds around. Choose a *Trefoil*, *Cinquefoil $(5,2)$* or *$(3,4)$ Torus Knot* to start from a real knot, or *Unknot (circle base)* to coil around a plain circle.
3. **Set the Cable Levels** — how many times to wind. $0$ leaves the bare base knot; each level adds a finer coil, so $2$–$3$ already reads as a fractal.
4. **Tune the winding and radius per level.** **First Winding** is the number of turns the first cable makes around the base; **Winding Multiplier** is how much that turn count grows at each deeper level; **First Radius** is how far the first cable sits out from the base, and **Radius Ratio** ($<1$) shrinks that offset each level so the coils nest.
5. **Set the resolution and output.** **Samples** is the number of points along the curve — it must comfortably exceed the highest winding number (several times over) or the fine coils alias; **Tube Radius** and **Bevel Resolution** control the rendered rope. The result is a single closed curve object.
6. **Read the report.** The status line prints the point count and the number of cable levels actually applied.

## How it works

**In plain terms.** Think of an old coiled telephone cord. Now imagine that cord is itself made by coiling a thinner cord, and *that* thinner cord is a coil of a thinner one still — a spring wound out of a spring wound out of a spring. That is a fractal knot by **cabling**: you take a starting loop, replace it with a thin strand that spirals tightly around where the loop used to be, then do the same to the result, again and again. Each round of spiralling is faster and tighter than the last, so the shape looks the same whether you glance at the whole thing or zoom into one little coil — the meaning of *self-similar*. Because all of this happens with real strands in real 3-D space, you never have to draw a flat picture and worry about which strand crosses over which; the strands simply don't touch, and the over/under weave you see is just the honest geometry. The math below makes "spiral around a curve" precise and deals with the one subtlety — how to point the spiral consistently as it travels along a bending curve.

**One cabling pass.** Given a base curve $\gamma_k(t)$, the next level winds a helix around it:

$$\gamma_{k+1}(t)=\gamma_k(t)+r_k\big(\cos(\omega_k t)\,\mathbf{u}(t)+\sin(\omega_k t)\,\mathbf{v}(t)\big),$$

where $\mathbf{u}(t),\mathbf{v}(t)$ are two unit vectors spanning the plane perpendicular to the curve at parameter $t$. Read the formula geometrically: $\gamma_k(t)$ is where you are on the old curve, and the bracketed term steps you a distance $r_k$ out into the normal plane at an angle $\omega_k t$ that keeps turning as $t$ advances — so you trace a circle *around* the curve while sliding *along* it, i.e. a helix wrapped on the curve. Each pass multiplies the turn rate ($\omega_{k+1}=\text{mult}\cdot\omega_k$) and multiplies the offset by the radius ratio ($r_{k+1}=\text{ratio}\cdot r_k<r_k$). Growing frequency and shrinking amplitude by constant factors is precisely what makes level $k+1$ a scaled-down replica of level $k$, and hence the limit self-similar.

**The frame problem.** For the helix to make sense at every point you need the two axes $\mathbf{u},\mathbf{v}$ of the normal plane — but the normal plane has no *canonical* pair of axes, and the textbook choice, the **Frenet frame**, fails badly here. It is defined from the curve's curvature vector, so it is undefined wherever the curve momentarily straightens (curvature zero) and it whips through a half-turn near inflection points. A cable built on it would lurch and kink at exactly those places. The construction instead carries a **rotation-minimising (Bishop) frame**: starting from one arbitrary normal, it transports the pair along the curve turning them only as much as the curve's own bending forces, and no more. The result is a smooth pair of axes everywhere, even across straight stretches — the natural "don't add twist" frame for wrapping a cable.

There is one catch that only a *closed* loop exposes. Transport a Bishop frame all the way around a loop and it generally does **not** return to where it began: it comes back rotated by a leftover **holonomy** angle $\phi$. If ignored, the end of the cable would meet its own start at that angle $\phi$ and leave a visible seam. The code measures $\phi$ across the closing edge and then unwinds it, distributing a compensating rotation $\phi\,t/2\pi$ uniformly around the loop so the frame closes up exactly. Spread evenly, this correction adds an imperceptible, constant background twist and the cable joins seamlessly.

**Why no crossing bookkeeping is needed.** This is the real payoff over the planar route. Because the offsets shrink geometrically, each level's tube fits *strictly inside* a tube around the level before it, so the successive coils never collide and the whole curve stays **embedded** — genuinely disjoint from itself in space. All the over/under weaving that a diagram-based method must reason about explicitly here falls out for free: sweep a tube along the curve and the crossings render correctly simply because there are no true intersections to resolve.

That same shrinkage is what *bounds* the construction. Each new coil has to fit inside the previous coil's tube and clear of the base curve's own bends, so the radius ratio cannot be pushed too high; past a threshold the cable eats into itself, and once the curve self-intersects it loses both its knot type and the automatic weave. Keeping the ratio comfortably below $1$ is therefore not just cosmetic — it is the condition that the object remains a knot at all.
