# Math Art — Generator Gallery

Every generator in the Math Art extension. Click any shape for its documentation — an overview, the configuration options, the underlying mathematics, and references.

Each shape is generated centered on the origin fitting a 2 m cube, and shown with a consistent studio render (regenerate them with [`render_docs.py`](render_docs.py)).
