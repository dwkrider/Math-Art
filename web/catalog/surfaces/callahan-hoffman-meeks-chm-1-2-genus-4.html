Callahan-Hoffman-Meeks CHM-(1,2) (genus 4)

Definition

No (g, dh) pair is stored: the shipped row is built by the dedicated mesher we.stinv_chm12_mesh (a torus/branched-cover or multi-patch assembly); no elementary (g, dh) pair on a plane domain is stored in the code. The shipped implementation is authoritative; an unverified transcription would silently define a different surface.
