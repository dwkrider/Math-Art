Fischer-Koch-Freese (twisted)

Fischer-Koch-Freese (twisted) is a singly periodic minimal surface, given by a Weierstrass representation, immersed, with a rod group.

Definition

No (g, dh) pair is stored: the shipped row is built by the dedicated mesher we.sfk_fkf_mesh (a torus/branched-cover or multi-patch assembly); no elementary (g, dh) pair on a plane domain is stored in the code. The shipped implementation is authoritative; an unverified transcription would silently define a different surface.
