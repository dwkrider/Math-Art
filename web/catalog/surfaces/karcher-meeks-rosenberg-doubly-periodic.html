Karcher-Meeks-Rosenberg (doubly periodic)

Karcher-Meeks-Rosenberg (doubly periodic) is a doubly periodic minimal surface, given by a Weierstrass representation, genus 1, 4 ends, embedded, with a layer group.

Definition

No (g, dh) pair is stored: the shipped row is built by the dedicated mesher we.dperiodic_mesh (a torus/branched-cover or multi-patch assembly); no elementary (g, dh) pair on a plane domain is stored in the code. The shipped implementation is authoritative; an unverified transcription would silently define a different surface.
