Riemann's Minimal Example

Riemann's Minimal Example is a singly periodic minimal surface, given by a Weierstrass representation, genus 0, embedded, with a rod group.

Definition

No (g, dh) pair is stored: the shipped immersion is a closed form in Weierstrass elliptic functions (zeta, wp) on a rectangular torus (math_art/minsurf/zoo.py, _riemann_X) -- outside the elementary expression language. The shipped implementation is authoritative; an unverified transcription would silently define a different surface.
